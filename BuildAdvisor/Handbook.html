Before you start

Build Advisor is a Script Extender mod. Install Script Extender once, then the mod, and it works from the next game start.

Script Extender and a mod manager

  1. Get BG3 Mod Manager (free). In it, choose Tools > Download and Extract the Script Extender. That installs BG3 Script Extender (version 20 or newer) in one click. Script Extender is a separate community project and is not included with this mod.
  2. Drag BuildAdvisor.pak into BG3 Mod Manager (or File > Import Mod), move Build Advisor to the active mods list, then Save Load Order and Export Load Order to Game.
  3. Start the game. If a Mod Verification dialog lists Build Advisor, tick it and choose Start Game.

Installing by hand works too: copy the pak to %LOCALAPPDATA%\Larian Studios\Baldur's Gate 3\Mods\ and enable it in the load order (a mod manager is the safe way to edit modsettings.lsx). The chapter below has the details for Build Advisor.

Using it with Loot Advisor

Build Advisor and Loot Advisor are separate mods; each works on its own. Installed together, Loot Advisor uses the build you picked in Build Advisor for each character, so the items it recommends match the build you follow. Loot Advisor is at https://github.com/md12ol/LootAdvisor.

Both read the game and never change your character. Treat them as a guide with spoilers: they name builds, item locations and the story choices that open or close them.

Build Advisor

Build Advisor shows the strongest community build for your character and marks the right choices while you make them. It knows 22 builds, from Patch 8 community rankings and from damage and defence models made for the origin companions, and suggests two or three for each origin character.

It is for players who want a strong character without reading a build guide on a second screen, and for anyone respeccing a companion with Withers. It only reads the game and changes the text of the game's own menus while they are open. It never changes your character or your save.

Every choice is marked. Stars on every named choice, rainbow outlines on tiles and spell icons, and targets on the ability rows. If a menu ever looks wrong, untick Highlight in game menus in the advisor window: the window keeps showing the full plan.

Marks inside the game's own menus

Every choice the build wants on the current screen is marked, in character creation, Withers' respec and every level-up. There are three kinds of mark.

  • A star in front of a name. Every choice that has a name in the menu gets a * prefix, which the game's font draws as a small star: race and subrace, class, subclass, background, deity (Clerics), skills and expertise, feats and the feat's own choices (for example * Resilient: Constitution), fighting styles, manoeuvres, invocations, metamagic, pact boons, draconic ancestry, favoured enemy and natural explorer, and the skill or cantrip a race lets you choose. Only the text changes; the menu works as before.
  • A rainbow outline on square picks. Tiles (race, subrace, class, subclass, background, deity) and spell and cantrip icons get the rainbow frame Loot Advisor uses for items, sized to the tile. Tiles keep the star on their name too. Spell and cantrip icons have no name in the grid, so they get the outline only. This covers new spells, prepared spells, spells a feat grants, and both sides of a spell swap.
  • Targets on ability rows, no star. Point buy shows the score to aim for: Strength (17, +2) means 17 is the final score and +2 is where your racial bonus goes; rows without a bonus read Dexterity (10). At level-up, the ability rows of an Ability Improvement or a half feat show the same kind of target, for example Dexterity (19, +2): the score after the raise, and the raise. Rows the build does not raise are left alone.
  • * Change appears on the skill button when your current proficiencies are missing one of the build's skills. Open the picker; the build's skills are starred there.

When you leave the screen, pick another build, or untick Highlight in game menus, every star, outline and target disappears and the menu looks as before.

How it works

Finding the screen. Twice a second the mod looks at what the game is doing: a level-up in progress, a Withers respec, a new character being created, or, if none of those, the party member you control. From that it reads the name, origin, race, classes with subclasses and levels, the class being taken, and the ability scores (point-buy values in creation, final scores otherwise).

Ranking the builds. Builds are listed in this order, without repeats: the origin's own list (two or three builds; the Dark Urge has one too); builds that start as the class you picked; builds that use that class; builds that contain every class you already have; and with Show all builds, the rest by tier. The first entry is recommended unless you picked another one for this character.

Working out this step. Each build has a level-by-level plan (class taken at each character level, the picks, and the exact menu labels to star). The mod compares that plan with the character:

  • race: best pick, good alternative, or change (origin races are locked and always pass);
  • class this level: the class you are taking against the plan's class for this level;
  • class split so far: a warning when your levels per class differ from the plan;
  • abilities: in creation, each point-buy value against the plan (with the +2 / +1 racial bonus); later, each final score against the plan's minimum.

Marking the menus. Once a second, while a creation, respec or level-up screen is open, the mod walks the game's menu and marks every entry whose name is exactly one of this step's picks, written the way the game writes it. Matching is exact, so "Shield" never stars "Shield of Faith" and the cantrip "Light" never stars the Light Domain tile. Tiles and spell icons get the rainbow outline, point-buy and ability-improvement rows get their target, and the skill button gets * Change when skills are missing. Every menu label in the 22 builds was checked against the game's own text, and each pick against what the game offers at that class level.

Known limitations

  • The in-menu stars match English labels. In other game languages only the window helps.
  • Text rows (skills, feats, manoeuvres, invocations…) get a star only; a script cannot recolour the game's menu text. Tiles and spell icons get the rainbow outline.
  • The "You need a guardian" screen is treated like your own character creation.
  • The newest marks (background, deity, feat choices, tile and spell outlines, level-up ability targets) have had the least testing. If one looks wrong, untick Highlight in game menus; the window still shows the plan.
  • Only the mouse-and-keyboard interface is supported; controller menus are laid out differently and are untested.
  • Builds are fixed. They reflect Patch 8 rankings and do not adapt to your gear or party.
  • If a game patch changes a menu, the affected part fails quietly. Untick Highlight in game menus if a menu looks wrong.

FAQ

Nothing opens when I press F7.

Check that Script Extender loaded (its console prints a line for each mod) and that Build Advisor is enabled. If you changed the key, the console line "[Build Advisor] loaded - press … to toggle" names it.

Can I follow a different build than the recommended one?

Yes. Pick it in the Build drop-down. The choice is saved per character and the stars follow it from then on.

My companion's levels don't match the plan.

The window warns you and keeps showing the plan's next step. Respec at Withers in camp (100 gold) to start clean; the mod guides the respec and every level-up after it.

Does it work for the Dark Urge or a custom Tav?

Yes. The Dark Urge gets a fixed list (the Throw-Thief first, the Throwzerker second), then builds for the class you pick. A custom Tav gets builds that start as, or use, the class you pick.

Will it break my save if I remove it?

No. It only reads the game and changes menu text while the menu is open.
